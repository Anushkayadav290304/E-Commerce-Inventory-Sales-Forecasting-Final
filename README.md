# E-Commerce Inventory & Sales Forecasting

An end-to-end retail analytics project focused on analyzing sales, inventory, product performance, regional performance, and demand forecasting using **Python, MySQL, ARIMA, and Power BI**.

## 📌 Project Overview

This project analyzes retail inventory and sales data to understand business performance and support demand forecasting.

The project covers:

- Data cleaning and preprocessing using Python
- Sales and inventory analysis
- SQL-based business analysis using MySQL
- Demand forecasting using ARIMA
- Interactive Power BI dashboards
- Product, category, store, and regional analysis

## 🛠️ Tools & Technologies

## 🐍 Python Analysis

Python and Pandas were used for data cleaning, preprocessing, and preparing the dataset for analysis.

The project also includes demand forecasting using the **ARIMA** time-series model.

Forecast results are available in:

`forecast_output.csv`

## 🗄️ MySQL Analysis

MySQL was used to perform SQL-based business analysis of the retail dataset.

The analysis covers:

- Sales performance
- Inventory levels
- Product performance
- Category performance
- Regional performance

SQL file:

`retail_inventory_sql_analysis (1).sql`

## 📁 Dataset

The cleaned dataset is available in:

`cleaned_retail_inventory.csv`

It contains information related to dates, stores, products, categories, regions, inventory, units sold, units ordered, demand forecasts, prices, discounts, seasonality, and revenue.
