# E-Commerce Inventory & Sales Forecasting

An end-to-end retail analytics project focused on analyzing sales, inventory, product performance, regional performance, and demand forecasting using **Python, MySQL, ARIMA, and Power BI**.

---

## 📌 Project Overview

This project analyzes retail inventory and sales data to understand business performance, identify sales and inventory patterns, and support demand forecasting.

The project covers:

- Data cleaning and preprocessing using Python
- Sales and inventory analysis
- SQL-based business analysis using MySQL
- Demand forecasting using ARIMA
- Interactive Power BI dashboards
- Product, category, store, and regional analysis

## 🐍 Python Analysis

Python and Pandas were used for data cleaning, preprocessing, and preparing the retail dataset for analysis and visualization.

The project also includes time-series demand forecasting using the **ARIMA (AutoRegressive Integrated Moving Average)** model.

### Python Tasks

- Data cleaning
- Data preprocessing
- Data preparation
- Sales analysis
- Inventory analysis
- Demand forecasting

## 📊 Power BI Dashboards

The project includes interactive Power BI dashboards designed to analyze different aspects of retail performance.

### 1. Executive Overview

Provides a high-level overview of important business metrics including sales, revenue, inventory, products, and stores.

### 2. Sales Performance

Analyzes sales performance and sales trends over time.

### 3. Inventory Monitoring

Provides insights into inventory levels and inventory-related metrics.

### 4. Product & Regional Analysis

Analyzes product, category, and regional performance.

### 5. Final Dashboard

Combines important project metrics and visualizations into an overall business dashboard.
